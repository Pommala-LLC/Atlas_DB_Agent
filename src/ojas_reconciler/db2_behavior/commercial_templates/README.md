# Commercial boundary templates

Export with `db2-behavior commercial-export-templates --output-dir <dir>`.
Edit the draft JSON, then run `commercial-seal-artifact` to validate it and add
a canonical digest. Draft or self-asserted artifacts do not create platform
authority.

RC25 also exports templates for pause disposition, procedure composition, and naming compatibility. These templates are unsealed drafts and confer no authority until validated, digest-bound, and approved through the appropriate customer workflow.
